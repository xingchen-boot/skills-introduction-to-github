以下是这些依赖项的作用：
@fingerprintjs/fingerprintjs：轻量级 JavaScript 库，收集浏览器公开信息（如浏览器类型版本、硬件特征、字体、WebGL 渲染信息等 ），经哈希处理生成设备指纹，用于匿名识别用户，可用于个性化体验、欺诈检测、匿名跟踪、多因素身份验证等场景 。
artplayer：一款视频播放器，可用于网页中播放视频，支持多种视频格式和播放功能，提供自定义播放界面、插件扩展等能力 。
artplayer-plugin-danmuku：是 artplayer 的弹幕插件，为 artplayer 视频播放器添加弹幕功能，增强用户互动性 。
axios：基于 Promise 的 HTTP 客户端，用于浏览器和 Node.js。可在浏览器中发送 XMLHttpRequests 请求，在 Node.js 中发送 http 请求，方便进行前后端数据交互，如获取 API 数据、提交表单等 。
echarts：百度开源的数据可视化图表库，提供直观、生动、可交互、可高度个性化定制的数据可视化图表，涵盖折线图、柱状图、饼图等多种图表类型，用于数据展示分析 。
element-plus：基于 Vue 3 的桌面端组件库，提供丰富的 UI 组件（按钮、表单、表格等 ），帮助开发者快速构建美观、功能齐全的 Web 应用界面 。
hls.js：JavaScript 库，用于在不支持 HLS（HTTP Live Streaming）协议的浏览器中实现 HLS 视频流播放功能，使浏览器能播放 HLS 格式的视频 。
js-md5：实现 MD5 哈希算法的 JavaScript 库，可将任意长度信息转换为固定长度哈希值，用于数据加密校验，如密码存储、文件完整性检查、数据签名等 。
mitt：简单的事件总线库，用于在 JavaScript 应用中实现发布 - 订阅模式，方便组件间通信，解耦不同模块 。
moment：处理时间和日期的 JavaScript 库，提供格式化、解析、操作日期时间等功能，简化日期时间相关操作 。
pinia：Vue 的状态管理库，用于管理 Vue 应用中的全局状态，取代了 Vuex，具有体积小、性能好、支持 TypeScript 等优点 。
sass：CSS 预处理器，扩展了 CSS 功能，允许使用变量、嵌套规则、混合等特性，使样式表更易维护和扩展 。
sass-loader：Webpack 的加载器，用于将 Sass/SCSS 文件编译为 CSS 文件，使 Webpack 能处理 Sass/SCSS 文件 。
vue：渐进式 JavaScript 框架，用于构建用户界面，通过组件化开发模式，可高效创建单页面应用和复杂 Web 应用 。
vue-cookies：Vue 插件，简化在 Vue 应用中对 Cookie 的操作，方便进行 Cookie 的设置、获取、删除等 。
vue-cropper：Vue 组件，用于实现图片裁剪功能，提供可视化裁剪界面，方便用户对图片进行裁剪处理 。
vue-draggable-plus：基于 Sortable.js 的 Vue 组件，使元素可拖拽，用于实现列表项拖拽排序、元素拖拽布局调整等功能 。
vue-router：Vue.js 官方路由插件，用于构建单页面应用，设定访问路径并将路径与组件映射，实现页面间的路由跳转 。
